# Транскрипт / конспект: MTProxy видео
Источник: https://www.youtube.com/watch?v=3O7iigCHd8U
Дата: 2026-03-24

## Краткий смысл
Видео про поднятие MTProxy для Telegram на VPS и про опциональную каскадную схему через второй сервер.

## Ключевые тезисы
- MTProxy используется как нативный прокси для Telegram.
- Можно работать без обычного VPN.
- Базовая схема: зарубежный VPS с MTProxy.
- Улучшенная схема: российский VPS как входной relay, который пересылает трафик на зарубежный MTProxy.
- Пользователь получает готовую ссылку или QR-код для подключения в Telegram.

## Что делает автор
- Покупает VPS.
- Подключается через Termius.
- Запускает кастомный скрипт установки.
- Скрипт ставит Docker и поднимает MTProxy.
- Предлагает выбрать домен маскировки.
- Предлагает выбрать порт, чаще 443.
- Показывает готовую proxy-link и QR.
- Для каскада поднимает второй скрипт на российском VPS.
- На втором сервере делается TCP-forward на основной MTProxy.
- В Telegram proxy-link подменяется IP на IP входного узла.

## Архитектура
### Прямая
Telegram client -> MTProxy VPS

### Каскад
Telegram client -> Russian relay VPS -> Foreign MTProxy VPS
